# Model 2 and source corrections — September 7, 2026

This implementation follows the initial review and the user's choice of a balanced default. It replaces the previous AI-campus default; it does not newly validate the underlying judgment ratings.

## Scoring changes

- Equal starting shares across eight factors; momentum is context only because it overlaps with ecosystem maturity and can also consume available capacity.
- Fit remains an explicit weighted mean. A separate delivery concern group uses the lower of headroom and permitting. Optional Delivery first prioritizes those groups before fit, without claiming to know actual project eligibility or connection dates.
- Price scoring now spans 5–35¢/kWh by default, distinguishing the expensive states previously clipped together at 13¢. These are editable preference anchors, not calibrated economics. Invalid input retains the previous valid scale.
- Exact ties share a rank. One-rating sensitivity shows how changing one provisional rating by one level affects a state's rank against unchanged competitors. This is not a confidence interval and does not model correlated uncertainty.
- The legend uses the full fixed 0–100 range. Zero-weight scenarios have no scores or ranks. Fixed reference views preserve custom priorities.

Equal weights are an understandable starting point, not a demonstrated optimum. The seven 1–5 inputs, their equal numerical spacing, and the new delivery thresholds remain assumptions. The page and profiles explicitly disclose this. No new objective ratings have been invented to fill evidence gaps.
